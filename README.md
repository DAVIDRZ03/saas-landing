# 🚀 SaaSify - Modern Dark Landing Page

Landing page profesional para una plataforma SaaS, construida con una arquitectura de componentes limpia, diseño responsivo en modo oscuro y precios localizados en Quetzales (GTQ).

![SaaSify Preview](https://raw.githubusercontent.com/DAVIDRZ03/saas-landing/main/src/assets/hero.png)

🔗 **Demo en Vivo:** [https://saas-landing-x.vercel.app](https://saas-landing-x.vercel.app)

---

## 🛠️ Tecnologías Utilizadas

* **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
* **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/) (usando el plugin oficial `@tailwindcss/vite`)
* **Iconos:** [Lucide React](https://lucide.dev/)
* **Despliegue:** [Vercel](https://vercel.com/)
* **Control de Versiones:** Git & GitHub

---

## ✨ Características Clave

* 🌙 **Diseño Dark Mode:** Interfaz moderna y elegante basada en tonos `slate-950` e `indigo-600`.
* 📱 **Totalmente Responsiva:** Adaptada para dispositivos móviles, tablets y monitores de alta resolución.
* 🧩 **Arquitectura Modular:** Dividida en componentes limpios y mantenibles (`Navbar`, `Hero`, `Features`, `Pricing`, `Footer`).
* 🇬🇹 **Precios Localizados:** Estructura de planes ajustada para el mercado local en GTQ.
